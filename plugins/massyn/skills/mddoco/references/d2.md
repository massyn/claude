# D2 diagrams

A ` ```d2 ` fenced block is compiled by the [`d2`](https://d2lang.com) command-line tool while mddoco builds
the document, and embedded as inline SVG. The output needs no scripts, works offline and prints to PDF
without waiting for anything to load (unlike Mermaid, which is drawn in the browser from a CDN).

````markdown
```d2
direction: right
client: Client {shape: person}
server: Server {
  api: API
  db: Database {shape: cylinder}
  api -> db
}
client -> server.api: request
```
````

## Requirement: the d2 CLI

`d2` is a separate program, not a Python package, so `pip install mddoco` does not provide it. It is only
looked up when a document contains a `d2` block; documents without one never need it. If it is missing the
build stops with an error pointing to the install guide.

Check with `d2 --version`. Install with one of:

| Platform | Command |
|---|---|
| macOS (Homebrew) | `brew install d2` |
| Linux and macOS (install script) | `curl -fsSL https://d2lang.com/install.sh \| sh -s --` |
| Windows (Scoop) | `scoop install main/d2` |
| Windows (Chocolatey) | `choco install d2` |
| Any platform with Go | `go install github.com/d2lang/d2@latest` |

Installing changes the user's machine, so ask before running an install command. In CI, install `d2`
before the render step (download a pinned release archive from github.com/d2lang/d2/releases).

## Behaviour to know about

- **Errors stop the build.** A block that fails to compile fails the whole render with D2's own message,
  exactly like an invalid `graph` block. A block that takes longer than 30 seconds to compile fails with a
  timeout error.
- **Sizing:** the SVG carries its natural size and is capped at the page width by every built-in theme
  (`max-width: 100%`). It is centred like a Mermaid diagram. A custom theme should style `.d2` and
  `.d2 svg` itself (see [themes.md](themes.md)).
- **Site themes:** `site-*` themes render D2 diagrams the same way, at build time.
- **Templates:** a `d2` block works inside a `.md.j2` file, so Jinja can generate the diagram source from
  data. The block is compiled after Jinja has rendered.

## Choosing between diagram types

- `d2`: structure and architecture where layout quality, containers, shapes (`person`, `cylinder`, ...)
  and PDF output matter, and the `d2` CLI is available.
- `mermaid`: flows, sequences and Gantt charts when no extra tool should be required (browser-rendered, so
  needs network access for the CDN).
- `graph`: numbers.
